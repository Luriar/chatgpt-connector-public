# webjjonku V2

## 목표
일반 Chat에서도 사용자가 MCP 함수명을 몰라도 자연어 요청만으로 Cowork에 가까운 로컬/웹/문서 작업을 수행하도록 실행 계층을 강화한다.

## 구현 완료
- lifecycle daemon: HTTP MCP + tunnel 감독, 자식 프로세스 자동 재시작
- tunnel: off / quick / named 모드 + tunnel_status / tunnel_validate_named
- Skill: skill_list / skill_match / skill_get, Agent Plugins 1.0 형식 Skill 3종
- Plugin 패키징: plugin.json + skills, 실제 HTTPS MCP URL이 있을 때 mcp.json 자동 포함
- 권한 정책: allow / ask / deny
- 1회성 승인: approval_request → approval_grant → 다음 action 실행 시 자동 소비
- scheduler: interval / cron / one-shot at / file-change
- Playwright 브라우저: open/tabs/read/click/type/wait/screenshot/download/close
- 문서: XLSX range read/write, DOCX/PPTX text extract/replace, PDF extract/create
- SaaS REST: GitHub/Slack/Google/Gmail/Drive 템플릿 + 환경변수 토큰 기반 generic REST 연결
- exec_secure: Docker 컨테이너에 승인 root만 /work로 마운트하는 격리 실행
- sandbox_status: Docker Desktop이 반기동 상태여도 무한대기하지 않도록 timeout/engine readiness 검사
- npm run daemon / status / plugin:package
- Windows 자동 시작: scripts/install-autostart.ps1

## 외부 환경이 필요한 항목
### Cloudflare Named Tunnel
코드와 진단은 구현됐다. 현재 PC에는 cloudflared가 있으나 Cloudflare origin cert가 없어 계정 E2E는 진행 불가:
- cert.pem 없음
- cloudflared tunnel list가 인증 오류 반환
로그인/계정 인증 후 tunnel.name/configFile/publicBaseUrl을 설정하면 daemon에서 named mode 사용 가능.

### exec_secure
도구는 구현됐고 Docker engine readiness timeout도 적용했다.
현재 Docker Desktop은 설치돼 있으나 엔진 API가 준비되지 않아 실제 컨테이너 E2E는 환경에서 막힘. 엔진이 정상화되면 바로 사용 가능.

### 정식 ChatGPT Plugin 설치
Agent Plugins 1.0 ZIP은 생성 가능하다. 현재 이 Chat 세션에는 Plugin Creator의 create/upload 액션이 노출되지 않아 플랫폼 계정에 실제 생성/설치는 자동 수행하지 못했다.
현재 ZIP: dist/webjjonku-v2-plugin.zip
현재은 live HTTPS MCP URL이 없어 skills-only ZIP이며 WEBJJONKU_MCP_URL 또는 tunnel state의 mcpUrl이 있으면 mcp.json도 자동 포함한다.

## 사용
- daemon: npm run daemon
- 상태: npm run status
- 테스트: npm test
- Plugin ZIP: npm run plugin:package
- 자동시작: powershell -ExecutionPolicy Bypass -File scripts\install-autostart.ps1

## 보안
- 호스트 exec_command는 호스트 권한이므로 신뢰 코드에만 사용.
- 불신 코드/외부 repo/패키지 빌드는 exec_secure 우선.
- permissions action이 ask면 승인 없이 서버에서 실행 차단.
- SaaS token은 state/config에 저장하지 않고 지정한 환경변수에서만 읽는다.
