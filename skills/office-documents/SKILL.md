# Office Documents

Use excel_read_range/excel_write_range for spreadsheets.
Use office_extract_text/office_replace_text for DOCX and PPTX text operations.
Use pdf_extract_text/pdf_create_text for PDFs.
Preserve originals by writing to a new output file when the requested change is destructive or broad.
